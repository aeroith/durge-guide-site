Install

There is no public download yet. These are the steps used on the test machine. They'll carry over to a release.

What you need

  • Baldur's Gate 3. Only the native Linux build has been tested. See Compatibility for Windows.
  • The game set to English. In any other language, the quest, dialogue and item text stays silent.
  • Tutorials turned on in the game's options. Notes speak through the tutorial popup.
  • No Script Extender. It isn't needed.

Install it

  1. Close the game.
  2. Put DurgeGuide.pak in the game's Mods folder. On Linux that's ~/.local/share/Larian Studios/Baldur's Gate 3/Mods/.
  3. Enable it in modsettings.lsx. The included install.py does both steps, and keeps a backup of your settings.
  4. Start the game and load a save. Mod Verification opens. Choose Start Game. The story recompiles, so this load takes a little longer.
  5. Take a few steps. The first box explains your tier.

Existing saves work. There is no need to start again.

Change tier

With the game closed, run this from the mod's folder, naming minimal, normal or extensive:

./tier.sh extensive

It rebuilds and installs the mod. Mod Verification returns on the next load. Notes you've seen stay seen, though the journal will read differently.

After a game patch

The mod carries its own edited copy of the game's English text. A patch leaves that copy behind until you rebuild, so run tier.sh again. On Linux, the included systemd unit notices the change and rebuilds for you. It remembers your tier.

Remove it

Removing it in the middle of a run hasn't been tested. Keep a save from before you installed it.
