Install

There's no public download yet. These steps are how it's installed on the test machine today, and they'll carry over to a release.

What you need

  • Baldur's Gate 3. It's been tested on the native Linux build. See Compatibility for Windows.
  • The game set to English. Other languages won't show the quest, dialogue or item text.
  • Tutorials turned on in the game's options, because notes use the tutorial popup.
  • You don't need Script Extender.

Install it

  1. Close the game.
  2. Put DurgeGuide.pak in the game's Mods folder. On Linux that's ~/.local/share/Larian Studios/Baldur's Gate 3/Mods/.
  3. Enable it in modsettings.lsx. The included install.py does both steps and keeps a backup of your settings.
  4. Start the game and load a save. Mod Verification opens, so choose Start Game. The story recompiles, which takes a little longer than a normal load.
  5. Take a few steps. The first box explains your tier.

Existing saves work. You don't need to start a new game.

Change tier

With the game closed, run this from the mod's folder, using minimal, normal or extensive:

./tier.sh extensive

It rebuilds and installs the mod. The next load shows Mod Verification again. Notes you've already seen stay seen, and they'll read differently in the journal.

After a game patch

The mod carries an edited copy of the game's English text. After a patch, that copy is out of date until you rebuild, so rerun tier.sh. On Linux, the included systemd unit does this for you when the game's language file changes, and it keeps your tier.

Remove it

Removing the mod in the middle of a run hasn't been tested. Keep a save from before you installed it.
