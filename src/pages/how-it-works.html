How it works

For modders. Everything here is an Osiris story goal and data files. It needs no Script Extender, and runs on the native Linux build.

Popups and notices

An existing save never gains a mod's new level objects, so triggers placed in a level wouldn't fire. Instead, a timer checks the host's position once a second against a 16-metre grid of spots. Notes are UnifiedTutorial entries with the side-popup modal type, so they get the journal archive for free.

  • Two side popups can be on screen. A third call is dropped, but still counted as seen, so popups are spaced 6 seconds apart.
  • A popup raised under the loading screen is lost in the same way, so nothing fires until the party has moved.
  • ShowNotification takes raw strings, which gives the one-line notices.

Text in the game's own screens

A mod's localization file with the same handle doesn't override the game's text. What does work is shipping a full copy of english.loca inside the mod's pak. The build extracts the current file from the installed game, adds the notes to quest steps, dialogue lines and item descriptions, and packs it. That's also why a tier has to be chosen at build time.

Map pins

Journal markers need an existing object, so each one snaps to a vanilla object nearby. They stay hidden until ShowMapMarker is called, and the shown state is saved, so a timer shows only those within 160 metres. Pins clear on TemplateAddedTo or Opened. A marker in the final level (END_Main) makes older saves fail to load, so it has none, and the Iron Throne level is left out to be safe.

Saves and rebuilds

A save keeps the goal it was saved with until the mod's Version64 changes, so every build stamps a new version. The goal file is also renamed each build, which makes its INITSECTION run again.

Warnings

Points of no return use the same position check, with QuestIsAccepted and QuestIsClosed to list what's still open. Camp warnings hang off TeleportedToCamp and check quest steps with QuestUpdateIsUnlocked. The game has no event that lets a mod step in before a rest, so a warning on arriving at camp is the closest available.

Dialogue tags

The game's dialogue files are readable JSON once unpacked, with the writers' own notes on what a line does. Tags were matched to exact line handles using those files.
